## 3. CurrentScene / epoch (split done right)

Grok's pin split per the correction: truth vs steering vs rendering live in
separate objects — no monolithic ScenePin was created.
- Truth: Cortex `current_scenes` (per-field value/source/authority/
  confidence/updated_at) + `scene_epochs` log (migration 0030). Deterministic
  updater (`scene_state.py`): user_explicit > external > inferred; monotonic
  participant add, explicit-only removal. Routes: `scene/report`
  (detections + optional epoch close), `scene/epoch`, `scene/active` GET.
- Expression: overlay registry entries (lens/steer/scope as stance lines).
- Rendering: assembler budgets + live_scene module rule.
- Epoch close writes identity + snapshot reference + carried matter IDs only;
  async consolidation is a later slice and can never block reopening.
- Runtime keeps a local hot copy (`cachedScene` in session state, primed on
  new temporal sessions, refreshed from authoritative report responses);
  per-turn effective scene = cache + provisional Jev detections (marked,
  expire at turn end). No synchronous scene lookup per ordinary turn.
- Jev packs gained bounded scene-delta slots (arrivals/departures/addressee/
  activity as separate questions — no keyword direction parsing).
