# Longitudinal cognition thesis (research hypothesis — NOT a build mandate)

## Proven / implemented
The graduated operational substrate (`9aadba5` / `00e8364`) currently
supports longitudinal:

- **epistemic evidence/provenance** — raw transcript canonical; every derived
  row carries message/span/model provenance back to it;
- **temporal/lifecycle state** — expectations, loops, commitments, recurrences,
  suppressions with legal transitions, idempotency and audit trails;
- **attention** — ranked, pressure-dynamic, fatigue-aware surfacing with
  suppression dominance and wise-silence outcomes;
- **action/withholding** — owed vs available, receipts with identity/version
  fencing, HOLD creating no false history;
- **receipts/outcomes** — delivered/generated/asked/answered/ignored/deferred/
  dismissed/resolved evidence feeding future posture across sessions;
- **behavioural revision** — new evidence revives fatigue; resolution removes;
  suppression dominates; partial runs stay honest and retryable.

## Working hypothesis / next phase
We are not merely building memory. We are building systems that maintain and
revise **meaning** over time. Possible shape (hypothesis only — never one
service per box without evidence):

```
Evidence → World / Matter Model → Interpretation / Hypotheses
→ Convergence / Tension → Attention → Policy / Posture
→ Objective / Action Selection → Foreground / Tools → Outcome ↺
```

A **matter** is a promising general abstraction: an evolving thing with
identity across time that may accumulate evidence, actors, claims,
expectations, uncertainty, hypotheses, contradictions, actions, outcomes,
emotional/relational significance, deadlines and sub-matters. It is NOT yet
a universal root ontology — do not canonise it as one.

Interpretation principles (preserved, not yet implemented as machinery):

- salience is not meaning;
- confidence is not interpretation;
- lifecycle is not activation;
- multiple interpretations may coexist;
- supporting and contradicting evidence must not be averaged away;
- uncertainty may remain unresolved;
- product-specific projections may differ over shared evidence;
- policy/posture may be a reusable layer between cognition and expression;
- reactions to the system's own behaviour can teach future strategy.

RPD2, Sophie, Bloom and Oracle appear here only as stress/benchmark
environments demonstrating different requirements — never as reasons to
build product-specific concepts into the shared substrate.
