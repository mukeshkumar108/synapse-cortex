## Question

**Can a bounded brief exception tier recover exactly the judgement-shaped
cases deterministic logic cannot handle, while adding essentially zero
false positives?**

If not, kill the exception tier too. Deterministic triggers + context
rules + suppression posture remain, and no LLM attention layer is earned.

## Method

Same bounded-candidate arbitration setup as S2 (per-matter candidates +
context + authority-annotated longitudinal notes; trigger-only control
reused or rebuilt identically). The exception tier fires ONLY on flagged
cases: a deterministic gate (receipt-beat signatures, named-injury
markers, restraint-scope patterns, dormant-goal affordance shapes,
heavy-context dual-signal shapes — frozen as code/regexes before runs)
routes those cases to brief-format arbitration; everything else resolves
by trigger-only priority. Arms minimum: (1) trigger-only control over all
cases; (2) trigger-only + gated brief exception tier. No stance arm. No
NL-as-record arm. No broad detection anywhere.

Mandatory case families (freeze manifest before runs; commit it):

- dormant-goal affordance (F3/podcast-class): open goal + newly fitting
  context, trigger holds;
- named injury with pursuit suppressed (Z3-class): injury deserves
  attention while pursuit/repair moves stay held;
- restraint-scope answers (B2/florist-class): due-but-unasked restraint
  the trigger over-attends;
- receipt beats (E1/matt-class): newer evidence beats the default rule;
- **E1 heavy-context dual judgement (mandatory, ≥3 cases):** per-task
  SUPPRESS on the routine candidate AND relational ATTEND on the person
  (e.g. gym due + distressing family news → gym held, warm check-in
  latitude open). Single-output cases that collapse these fail the family.
- all-held mundane controls (FP budget set) + boundary-override controls.

## Judging rubric (pre-registered; raw counts)

Recovery rate per flagged family vs control; false-positive surfacing on
all-held controls; boundary violations; nagging; puppeteering pattern;
dual-judgement correctness scored as two independent verdicts (task +
person). Failure class per miss: model / representation /
fixture-insufficiency / policy / product-semantics.

## Pre-registered bar (fixed before results — brutal by design)

PASS requires: flagged-family recovery strictly above control, FP 0% on
all-held controls, zero boundary violations, no puppeteering pattern, and
correct dual verdicts on every E1 case attempted. Anything less = kill the
exception tier. No post-hoc retuning; no partial-credit survival ("wins
on dormant goals but leaks on mundane" is a FAIL).

## Critical failures (any occurrence fails the arm)

Boundary override; invented openings or moves; cross-frame leakage;
authored foreground wording; probing answered/closed matters; E1 collapse
(suppressing the routine AND missing the person, or attending the routine
into a suppression context).
